# BMW_Sales_Dashboard

# Project Overview:
This dashboard provides a comprehensive analysis of BMW sales data, offering insights into sales performance across various dimensions. It enables users to monitor key sales indicators, identify trends, and understand the distribution of sales by model, country, region, and sales channel.

# Key Metrics / Insights:
Sold Quantity: Total number of BMW vehicles sold.
Revenue: Total revenue generated from sales.
Revenue Year-to-Date (YTD): Cumulative revenue performance within the current fiscal year.
Top Country Sales for Selected Model: Highlights the leading countries in sales for specific BMW models.
Sales by Model: Breakdown of sales performance across different BMW models.
Sales by Country/Region/Channel: Analysis of sales distribution based on geographical locations and sales channels.
Sales Trends (Yearly): Visualization of sales performance over time.

# Tools & Technologies:
Power BI: Used for data visualization, dashboard creation, and interactive reporting.
DAX (Data Analysis Expressions): Utilized for creating custom measures and calculations within Power BI to derive key insights.
Excel: Likely used for initial data preparation and storage, serving as a data source for the dashboard.
